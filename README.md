### Hi, I'm Ali 👋

Backend & platform engineer — Java / Spring Boot, Kafka, Keycloak, multi-tenant microservices.

🚀 **[Steppr Flow](https://github.com/stepprflow/stepprflow)** — a multi-broker, resilient **workflow orchestration framework for Spring Boot**.
Async multi-step pipelines over **Kafka or RabbitMQ** with at-least-once delivery, retries, DLQ, signed security-context propagation, timeouts, idempotency, and an optional monitoring dashboard.
→ **[stepprflow.github.io/stepprflow](https://stepprflow.github.io/stepprflow/)** · [Maven Central](https://central.sonatype.com/artifact/io.github.stepprflow/stepprflow-core) · [Docker Hub](https://hub.docker.com/r/alimhin/stepprflow-monitor)

🧰 **[bqkit](https://github.com/bqkit/bqkit)** — a **Spring Boot starter for Google BigQuery**, built around the Storage Read API.
Read query results in Avro or Arrow, with optional service account impersonation on top of ADC and a `@ServiceConnection` for the BigQuery emulator with Testcontainers.
→ **[bqkit.github.io/bqkit](https://bqkit.github.io/bqkit/)** · [Maven Central](https://central.sonatype.com/artifact/io.github.bqkit/bqkit-spring-boot-starter)
